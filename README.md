# Chennai Mazhai

Hyperlocal rain forecast for Chennai, in plain words.

- **Next 2 hours:** radar nowcast (RainViewer past frames, projected forward along the rain's recent track)
- **Rest of today and the week:** five global weather models blended via Open-Meteo (ECMWF, GFS, ICON, GEM, JMA)
- **Side by side:** Tamil Nadu Weatherman's live Facebook feed

Not an official forecast. For warnings, follow IMD Chennai.
